## Template Variations

### Design Styles (2 per use case)
1. **Modern/Minimal** - Clean, professional, lots of whitespace
2. **Bold/Vibrant** - Eye-catching colors, gradients, animations

### Template Components
Each template should include:
- ✅ Compelling headline
- ✅ Clear value proposition
- ✅ Professional imagery/icons
- ✅ Action button (CTA)
- ✅ Form fields (if applicable)
- ✅ Trust indicators (badges, testimonials)
- ✅ Responsive design
- ✅ Close/exit button
- ✅ Mobile optimization

### Color Schemes
- **Professional:** Navy, Gray, White
- **Energetic:** Orange, Red, Yellow
- **Trustworthy:** Blue, Green, White
- **Luxury:** Gold, Black, White
- **Healthcare:** Teal, White, Light Blue
- **Education:** Purple, Orange, White
- **Finance:** Dark Blue, Gold, White
- **Food:** Red, Green, White

## Template Naming Convention
```
[Industry]_[UseCase]_[Style]_[Version].html

Examples:
- Plumbing_Emergency_Modern_v1.html
- Fashion_FlashSale_Vibrant_v1.html
- Legal_Consultation_Professional_v1.html
```

## Template Generator Tool

### Automated Template Creation
Create a PowerShell/Bash script that:
1. Reads template definitions from JSON
2. Applies industry-specific content
3. Uses predefined color schemes
4. Generates HTML with proper structure
5. Creates database entries
6. Generates thumbnails

### Template Definition Format
```json
{
  "industry": "Plumbing",
  "useCase": "Emergency",
  "style": "Modern",
  "headline": "24/7 Emergency Plumbing Service",
  "subheadline": "Fast Response • Licensed & Insured",
  "ctaText": "Get FREE Quote",
  "colorScheme": "professional",
  "formFields": ["name", "phone", "emergency_type"],
  "trustIndicators": ["24/7", "Licensed", "Insured", "5-Star Rated"]
}
```
